1. Today’s assignments & student PINs

Students get a new random PIN each time they request one (valid today only). To give a student a fixed PIN instead, type a 6-digit PIN and tap Save. “Reset” clears it so the student can request again.

2. Task list for this section

One task per line. Only this section uses this list.
Applies to every student in this section, even if a rule above assigns more.

3. Student reports

Students tap “Report code for teacher” and send you the code. Paste one or more codes here (one per line).

4. My teacher PIN

Set your own 6-digit PIN for this section’s teacher login (saved on this device).

5. Code helper

Paste student names (one per line). Copy the result into the students list of a section in the file’s CONFIG.
